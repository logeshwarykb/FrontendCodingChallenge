# Objects UI

React + Vite app that shows objects from https://api.restful-api.dev/objects as Bootstrap cards
(3 per row, 10 per page with pagination), with Add (POST) and Delete (DELETE) options.

## Tech
- React + Vite
- React Router (`/` dashboard)
- Redux Toolkit store + thunk actions (GET / POST / DELETE)
- Axios
- Bootstrap 5 + Bootstrap Icons (CDN)

## Run
```
npm install
npm run dev
```
